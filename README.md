# 长情 · changqing

> 为**长期相处的对话关系**设计的中文优先记忆系统。

[English](README.en.md)

`changqing` 只解决一个问题：一个陪你聊了 100 天、说过 9 万句话的 AI，
怎么才能**真的记得你** —— 包括刚才提过的那件小事，和三个月前随口说过的那个名字。

它不是把原话无限堆进上下文（一定会爆），也不是只靠向量检索（刚说过的话还没进检索库）。
它把记忆分成四层，让模型自己负责整理，并且**每一条事实都能回引到原话**。
